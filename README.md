# Hi, I'm Branislav

I build web and mobile apps, mostly in TypeScript. My usual stack is React,
Next.js, and PostgreSQL, with React Native and Expo for mobile. I also write Go
services, Python tools, and native macOS apps in Swift.


A few things I've built:

- [Spend212](https://github.com/bmikuska46/trading212-expense-tracker) - a
  self-hosted expense tracker for Trading 212 and bank statements.
- [Video to Minecraft](https://github.com/bmikuska46/video-to-minecraft) - an
  experiment that turns a phone video of a room or object into a Minecraft world.
- [Plane Tracker](https://github.com/bmikuska46/mac-airplane) - nearby aircraft
  on a map in your Mac's menu bar.
- [IDSK components](https://github.com/bmikuska46/idsk-shadcn) - React components
  for the Slovak public services design system, built in the shadcn/ui style.

Most of my day-to-day work is in private repositories.
